QATT Unicode

The proposed block for Quốc Âm Tân Tự (QATT), a script found in Hán Nôm texts: characters in a block of code points.

Draft – not part of the Unicode Standard. This page shows the block of the QATT Unicode Proposal – Draft. The block position is not assigned yet. The code points shown use the provisional base (Supplementary Private Use Area-A); only the offsets within the block come from the proposal. The glyphs in the chart are drawn by qatt.js; a prototype reference font (proposal section 7.2) is shown on the QATT reference font page. Data: qtng/qatt-unicode at (ucd/ draft files, proposal sections 5–7).

Rows are sixteen code points each. Select a cell for the details. The QATT glyphs are drawn by qatt.js (see also the reference font); dashed = format characters, circles = tone marks.

List of code points

One row per code point with the full name from the draft names list: QUOC AM TAN TU <NAME> UNMARKED or MARKED-1 to MARKED-6 (the position of the marking stroke); in the names DD stands for đ and DZ for d. The code points are provisional (base ).

Overview

The 22 Cán

Each Cán has seven forms: one without marking stroke and six with the marking stroke in one of the six positions; the seven forms of a base are consecutive code points (unmarked first). The marking stroke at position 1 is the marked Cán of the source listing, positions 2 to 6 are the five Chi. The names are the sound names of the source listing (initial + ông); DD stands for đ and DZ for d.

Tone marks

Eight combining marks, one per tone, placed in the four corners of the cluster: the traditional tone order of the eight tones (âm before dương). The drawings are schematic, taken from the description in the proposal (the open side of the semicircle faces the centre); they are not reference glyphs.
