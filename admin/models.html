Definitions (db/translate_log.sql)

Try: one request of the function to one model of Gemini. Worked = status 200. Over quota = 429, the key has no more requests for that model at the moment (the model is skipped for a minute afterwards). Overloaded = 503, the model has too much demand. Other = every other status and tries without an answer. The times are those of working tries.

Translation: one call of the translator page. Whole call = from the request to the answer, including tries that failed before. Own characters = share of the words for which the model gave a character that is not in the list of the page. Fallback = the model's answer was unusable twice and the page got the first option of every syllable.

Tries are recorded since the function version of 16 Oct 2026, translations a few hours earlier. No text of a sentence and no user is stored.
