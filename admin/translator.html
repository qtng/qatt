Definitions (db/translate_log.sql)

Missing word: a word for which the model gave a character of its own (or "?" when it knew none) because the list of the page had no suitable character. "The dictionary has: nothing" = no character at all for this word, "n characters" = it has some, but none fitted. In the newest list the word is marked, with the words before and after it (5 if the user has the switch "Help improve the model" on, else 1; fewer or nothing there = the word is near the start or end of the sentence). Only these words are stored, not the whole sentence.

Language: the language of the free translation that was asked for. Errors = no answer (busy, over quota, ...). Fallback = the model's answer was unusable twice. Own characters = share of the words that are missing in the dictionary. Recorded since 16 Oct 2026.
