Definitions (db/translate_log.sql)

Gap: a word for which the model gave a character of its own (or "?" = it knew none) because the list of the page had no suitable option. Stored with the word before and after, "before | word | after", "-" where there is none, in Quốc Ngữ and as the characters chosen for the three. Only these words, not the sentence. Options on the page = how many characters the dictionary offered for the word: 0 means the dictionary has nothing, more than 0 means none of them fitted.

Language: the language of the free translation that was asked for. Errors = no answer (busy, over quota, ...). Fallback = the model's answer was unusable twice. Own characters = share of the words that are gaps. Recorded since 16 Oct 2026.
