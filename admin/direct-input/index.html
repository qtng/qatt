Direct QATT input prototype

Type QATT without Quốc Ngữ: a key is a shape (onset first, then rhyme), a digit puts a marking stroke on the last shape, the tone keys set the tone. The keys are the positions on the keyboard (event.code), so the layout of the keyboard does not matter. Space ends a cell, Backspace takes back the last part.


  

  
Clicking a key does the same as pressing it. The map is the constant MAP in direct-input.js; the rows are those of the symbol table (8, 8 and 6 shapes).
