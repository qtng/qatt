What this is

QATT (Quốc Âm Tân Tự) is a script for Vietnamese, built in the 1840s and encoded here as Private Use Area code points. The source code is the GitHub repository qtng/qatt (branch main, files are readable at https://github.com/qtng/qatt/blob/main/<path>). It holds the public website at qatt.org: the explanation of the script, a symbol table, an editor, a game (Spell it!), fonts, a Unicode proposal draft, and admin pages. It is plain HTML and JavaScript with Bootstrap, and has no build step.

Read this first

  • qatt.html: the script in detail (shapes, marks, tones, how a syllable is written). Start here for any question about the system.
  • js/qatt-text.js: encoding and decoding of QATT text (syllable, word, convert, decode).
  • symbols.html: the 22 base shapes and their order.
