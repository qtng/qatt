QATT reference font

The reference font for the QATT Unicode proposal: all 164 characters of the draft block (monospace, one square per character, code points from U+F0000), drawn from the strokes of qatt.js. The two format characters have a small square as placeholder. This is a prototype; stroke widths and proportions may still change. Large: the font. Small underneath: the same glyph drawn by qatt.js. Click a character to add it to the sample field.
