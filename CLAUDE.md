# qtng/qatt

The QATT site (Quốc Âm Tân Tự), served at the root of `qatt.org`: plain HTML and JavaScript with Bootstrap, no build step, GitHub Pages.
All instructions (the four repositories and how they belong together, URL rules, translation, and everything about this repository) are in the private repository `qtng/chunom-private`, file `CLAUDE.md`, section "The public repositories"; attach it with `add_repo` when a session starts here. Nothing technical is written in this public file.
Always: Root paths without a folder prefix (`/js/navigation.js`); no cache busters (`?v=N`) unless a copy is kept for ever; texts of the interface are translated with `data-vi` (a tag of its own without tags inside); tools, SQL, font build and private data are not here.
