PA script specification

A phonetic script for Vietnamese syllables: a stem cell for onset and nucleus, an extension cell for coda and tone.

Draft. Version 0.1. The code points are provisional and lie in the Supplementary Private Use Area-A. There is no reference font yet, so this page shows no glyphs.

Syllable grammar

A syllable is written with the four kinds of component of a Vietnamese syllable: onset (A), nucleus (N), coda (C) and tone (T). The nucleus includes the glide: oa, uy and similar are nuclei of their own.

Syllable  = Stem [ Extension ]
Stem      = A N
Extension = C [ T ]  |  T
  • A stem always has an onset. A syllable without an onset uses the onset _, which has a shape of its own.
  • A coda without a tone is a valid extension (tai, ngang tone). A tone alone is a valid extension (an open syllable with a tone).
  • A nucleus never stands without an onset. An onset may stand alone (a lone consonant).

Visually a syllable has at most two cells: the stem cell (A and N in one glyph) and the extension cell (C and T in one glyph, or C alone, or T alone).

Character repertoire

23 onsets, 22 nuclei, 10 codas and 6 tones are encoded, 61 characters in all. The combined glyphs are not encoded: the font builds them from sequences (see Composition).

Code points

The classes lie in separate ranges, so the class of a character is known from its code point and a sequence is validated with a regular expression. The block starts at U+F0800, well behind the provisional QATT range (U+F0000..U+F00AF), which stays free for growth.

Composition

A font renders the sequences with glyph substitution (OpenType ccmp, ligatures). No joiner or other control character is needed, because the classes tell what belongs together.

SequenceResult
A Nstem glyph (506)
C Textension glyph with coda and tone (60)
Aonset cell alone (23)
Ccoda cell alone (10)
Ttone cell alone (6)
N without A in frontnot valid; an input method inserts the onset _

A stem followed by a tone alone (A N T) is two cells. Every glyph is one cell wide.

One font with QATT

PA is designed to share one font file with QATT. For that the two scripts must not touch each other:

  • Code points. QATT uses U+F0000..U+F00AF, PA U+F0800..U+F085F. Nothing overlaps, and QATT keeps room to grow.
  • Control characters. PA uses no joiner or combiner. The QATT joiner (U+F009A), combiner (U+F009B) and tone marks (U+F009C..U+F00A3) have no meaning in PA text, and a PA tone is not a QATT tone mark.
  • Rules. The substitutions of each script act only on the classes of that script (@A @N @C @T for PA), so a QATT cell next to a PA cell is never combined with it. The two sets of rules can sit in the same ccmp feature as separate lookups.
  • Size. PA adds 605 glyphs (506 stems, 60 extensions and 39 single cells), well inside the glyph limit of a font next to the QATT forms and pairs.
  • Metrics. Both scripts use the same square cell, so mixed text keeps one line height and advance.

Reading Quốc Ngữ

A syllable of Quốc Ngữ is split into onset, nucleus, coda and tone, then mapped to the names above.

  • Tone. The accent of the vowel gives the tone and is removed: sắc 1, huyền 2, hỏi 3, ngã 4, nặng 5. No accent: no tone.
  • Onset. k and q are c; gh is g; ngh is ng; d is dz; đ is d; g before i is gi. No onset is _.
  • Glide. qu is the onset c plus a glide nucleus (quô is read as uâ). The glide forms oa, oă, uơ, uâ, uê, oe, uy, uyê are the nuclei wa, wae, war, waer, we, wer, wi, wir.
  • Coda. o after the nucleus is U, y is I.
  • Short a. a before the codas u, y, nh, ch is written with the nucleus ae (ă).

The earlier font

The earlier PA font pa.ttf of the old site has the same repertoire in the Basic Multilingual Plane private use area (U+E001..U+E272, with the tone 6 missing). Its code points convert to this block:

Open points

  1. Tone after a stem. The drawings have two forms: a small tone inside the stem cell and a full-size tone as a cell of its own. Proposal: the full-size cell is the default (as in the earlier font); the small form is chosen with the variation selector U+FE00 after the tone.
  2. Tone 6. The drawings have a sixth tone mark; its meaning is not yet decided (for example an explicit level tone).
  3. Combinations that Vietnamese does not use (for instance b with a glide nucleus). Proposal: the font draws all 506 stems, the input method decides what is offered.
